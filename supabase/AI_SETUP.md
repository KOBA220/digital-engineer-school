# Claude開発アシスタント

モデル: claude-sonnet-5-5。通常入力$2/100万token、出力$10/100万token。
学校全体の月上限は$20。表示は1ドル150円の概算（税・為替変動は含まない）。
予算月は日本時間。各実行前に$0.10をDBで予約し、成功後に使用トークン分へ精算。
送信JSONは16KBまで、出力2000tokensまで、ユーザー毎に1分5回まで。
タイムアウトは課金の可能性があるため予約額を保持。自動リトライなし。
管理者は利用履歴とAnthropic請求を照合して不確定な予約額を調整する。
API単価が変更された場合は費用計算と予約額を更新する。

## 有効化
1. 選択中のコード、指示、選んだAIスキル本文をAnthropicに送ることを利用者が了承する。
2. school-ai Edge Functionを配備する（verify_jwt=true）。
3. SupabaseのEdge Functions > Secretsに ANTHROPIC_API_KEY を設定する。
   APIキーはGitHub、config.js、チャットに記載しない。
4. Anthropic Consoleでクレジットを購入。自動補充はオフにして支出を管理する。
5. 学校の開発部屋でファイルを選び、短い質問で接続を確認する。

## 権限と送信範囲
ログイン済み、学校に入校許可済み、プロジェクトowner/editorのみ実行可能。
APIキーはサーバーのみ。プロジェクト全体や会話履歴を自動送信しない。
AI生成履歴はプロジェクト閲覧者が参照可能。
修正は比較画面で確認した場合のみ校内下書きに適用する。GitHubへのpushはしない。
